## 작업 목적

P0.3에서 확정된 **뉴스 데이터 소스**를 사용하여, 종목별 최근 뉴스(실적, 가이던스, 규제, 소송, 정치적 리스크 관련)를 수집하고 저장하는 기능을 구현한다. 이 데이터는 P2.3(뉴스 부정성 판단)의 입력이 되며, 요구사항 5.4-(2)에 명시된 대로 **가격과 독립적으로 조기경보를 발생시킬 수 있는 선행 트리거**역할을 한다.

## 쉬운 설명

"매일 정해진 종목들(예: AAPL, MSFT)과 관련된 뉴스를 자동으로 찾아와서 저장하는 프로그램"이다.

예를 들어:
1. "Apple, Inc." 또는 "AAPL"로 뉴스 검색
2. 최근 1~3일 동안 나온 뉴스를 찾아온다 (실적 발표, 제품 출시, 소송 뉴스 등)
3. 제목, 링크, 출처, 발표 시간을 저장한다
4. 내일 또 같은 작업을 반복한다

**중요한 점**: 가격이 아직 떨어지지 않았어도, "실적 부진" 또는 "규제 리스크" 뉴스 자체만으로 조기 경보가 울릴 수 있어야 한다. 즉, 뉴스는 사후 설명용이 아니라 선행 신호다.

## 필요한 입력

- P0.3에서 확정된 **뉴스 데이터 소스** (API, RSS 피드, 웹크롤링 등)
- **뉴스 유형 분류 기준** (어떤 뉴스가 "부정적"인가? — 요구사항 5.4-(2)에서 지정한 유형)
  - 실적 발표 / 실적 전망(가이던스)
  - 규제 / 소송 / 정치적 리스크
- **종목 리스트** (뉴스 검색에 사용할 종목 기호 또는 회사명)
- **데이터 저장 위치** (DB 또는 파일)

## 수행 순서

2. 프로젝트 스캐폴드에 `src/data_collection/news.py` (또는 해당 언어의 파일) 생성

3. 뉴스 수집 함수 구현
   ```python
   # 예시: NewsAPI 사용 시
   import newsapi
   
   def fetch_news(ticker, company_name, days=3):
       api = newsapi.NewsApiClient(api_key='...')
       articles = api.get_everything(
           q=company_name,
           sortBy='publishedAt',
           language='en'
       )
       return articles
   ```

4. 뉴스 유형 분류 로직 추가 (간단한 키워드 기반)

   ```python
   def classify_news_type(title):
       if any(word in title.lower() for word in ['earnings', 'guidance', 'profit']):
           return 'earnings'
       elif any(word in title.lower() for word in ['regulation', 'lawsuit', 'sue']):
           return 'regulatory'
       return 'other'
   ```

5. 데이터 저장 로직 구현
