## 작업 목적

뉴스 신호를 고도화하여, 현재의 종목별 뉴스 분류(실적/규제/정치 리스크)에 **애널리스트 다운그레이드/목표주가 하향** 카테고리를 추가하고, 특정 종목에 국한되지 않는 **시장 전체/거시경제 뉴스(공통 뉴스)를 별도 수집**하여 이메일 리포트의 참고 맥락으로 제공한다.

이는 요구사항 문서 §5.3(뉴스 신호)과 §5.4(신호 판단 기준, 특히 (2) 뉴스 기반 신호)를 구현하기 위한 것이다.

### 현재 상황

### 변경 내용

#### 1. 애널리스트 다운그레이드 카테고리 추가
- **무엇**: "목표주가 인하", "매수 → 중립으로 다운그레이드" 같은 애널리스트 뉴스를 새 카테고리(`analyst_rating`)로 인식한다.
- **언제 쓰임**: 가격 하락과 함께 발동하는 "매도" 알림의 이유 중 하나가 된다. 단, 목표주가 하향은 후행 신호라, 일반 가격 문턱(-5%)이 아니라 더 강한 문턱(-8%)을 요구한다.
- **예시**: 가격 -9% + 애널리스트 다운그레이드 뉴스 → 매도. 하지만 가격 -6% + 애널리스트 다운그레이드만으로는 매도가 아님(비중축소 정도).

#### 2. 시장 공통 뉴스 수집 및 맥락 표시
- **무엇**: 금리 인상, 인플레이션 악화, S&P500 전체 조정 같은 종목 무관 뉴스를 별도로 수집한다.
- **역할**: 종목별 등급이나 점수를 직접 바꾸지 않는다. 대신 맥락을 보정한다.
  - 예: 가격 데이터만으로는 "MSFT 고유 하락"(`stock_specific`)으로 보여도, 공통 뉴스에 "Fed 기준금리 인상"이 있으면 "시장 전체 뉴스로 뒷받침되는 하락"(`market_wide_news`)으로 라벨을 명시해 근거 출처를 투명하게 한다.
- **이메일에서의 표시**: 이메일 리포트 맨 위에 "[오늘의 공통 시장 뉴스]" 섹션으로 한 번만 표시(종목별 블록에 반복 안 함).

#### 3. 데이터 안정성 강화 (신규)
- 동일 날짜 중복 레코드 제거 → 재실행 횟수가 가중치 자동조정을 우회하지 않게 함
- 공통 뉴스 수집 실패 시 파일 유지 → RSS 장애로 전날 데이터 소실 방지
- 거시경제 부정 패턴 확장 → "금리 인상", "국채 급등" 같은 핵심 신호를 더 정확히 인식

## 결과물

### 1. `app/news_signals.py` — 뉴스 분류 확장

**`CATEGORY_PATTERNS` 딕셔너리**:
- `analyst_rating` 키를 맨 처음에 배치(우선 매칭)
- 정규식: `downgrade`, `price target + (cut/lower/reduc)`, `(cut/lower/reduc) + price target`, `underweight rating`, `sell rating`, `analyst...downgrade/cut/lower...rating/price target` 패턴 포함
- 거리 제한: `.{0,20}` 또는 `.{0,25}` 등으로 단어 사이 거리 유한화

**`MACRO_NEGATIVE_PATTERN`** (신규, 개선됨):
- 종목별 뉴스용 정규식이 잡지 못하는 거시경제 악재(hike, rate, yield, inflation, recession, correction, volatility, downturn, bear market 등) 포함
- `\brout\b` 경계 강화, `raises?.{0,20}rate` 패턴 확장으로 오탐/미탐 개선

**`classify_common_news()` 함수**:
- 입력: `news_dir: Path`, `filename: str` (기본값 `"_market.json"`)
- 동작: 공통 뉴스 파일 읽기 → 기존 정규식 + `MACRO_NEGATIVE_PATTERN`으로 분류 → 부정 감성 뉴스 반환
- 견고성: 파일 부재/JSON 손상 시 빈 리스트 반환

### 2. `app/grading.py` — 매도 등급 트리거 확장

**`STRONG_NEWS_CATEGORIES`**:
```
{"earnings_guidance", "regulatory_legal_political", "analyst_rating"}
```

**`SELL_REQUIRES_STRONG_PRICE`** (신규):
```
{"analyst_rating"}
```

**`evaluate_signal()` 함수 로직**:
- `easy_strong_news`: 실적/규제만 포함
- `hard_strong_news`: analyst_rating만 포함
- 매도 조건: `(price_signal and easy_strong_news) or (strong_price_signal and hard_strong_news)`
  - 실적/규제: -5% 이상 하락 + 뉴스 = 매도
  - 애널리스트: -8% 이상 하락 + 뉴스 = 매도
- **임계값은 `load_thresholds()`에서 읽음** (이중화 제거)

### 3. `app/market_context.py` — 공통 뉴스 기반 맥락 보정

**`refine_with_common_news()` 함수**:
- 입력: `price_context: str`, `common_news_negative: bool`
- 동작:
  - `"stock_specific"` & `True` → `"market_wide_news"` (라벨만 보정)
  - 그 외는 입력값 그대로 반환
- 효과: 가격 기반 맥락 판정을 공통 뉴스 신호로 보강(등급/점수는 그대로)
