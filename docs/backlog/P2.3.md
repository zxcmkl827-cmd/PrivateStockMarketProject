## 작업 목적

요구사항 5.4-(2)에 명시된 **뉴스 기반 신호**: "가격이 아직 하락하지 않았더라도, 부정적 뉴스 자체가 독립적으로 조기경보를 발생시킬 수 있음"을 구현한다.

P1.2에서 수집된 뉴스를 분석하여:
- **부정성 점수** (0~1 또는 0~10 등)를 계산
- **뉴스 유형** (실적/가이던스, 규제/소송, 정치적 리스크 등)을 분류
- **신호 발동** (부정성이 일정 수준 이상인가?)

이 정보는 P2.4(등급 판정)에서 "유지관찰/비중축소/매도 결정"의 입력이 되며, P3.1(알림 메시지)에 "관련 뉴스" 요약으로 포함된다.

## 쉬운 설명

"종목 관련 뉴스를 읽고 '이건 부정적인 뉴스인가, 긍정적인 뉴스인가'를 판단하는 부분"이다.

예를 들어:
- "Apple Q3 earnings beat" → 긍정적
- "Apple cuts iPhone production guidance" → 부정적 (가이던스 하락)
- "Apple faces EU antitrust investigation" → 부정적 (규제 위험)

이를 자동으로 판단하려면:
1. 뉴스 제목/내용에서 "earnings", "guidance", "cut", "regulation", "lawsuit" 등의 키워드를 찾는다
2. 부정적 키워드("cut", "miss", "lawsuit")가 있는지, 긍정적 키워드("beat", "raise")가 있는지 확인한다
3. 감정 분석(sentiment analysis) 기법을 사용할 수도 있다 (NLP)

## 필요한 입력

- P1.2에서 수집된 **종목 뉴스 데이터**
- **뉴스 부정성 판단 기준** (요구사항 5.4-(2)에서 지정한 뉴스 유형):
  - 실적 발표 / 실적 전망(가이던스)
  - 규제 / 소송 / 정치적 리스크
- **부정성 점수 스케일**: 0~1? 0~10? 어떻게 측정할 것인가?
- **신호 발동 임계값**: 부정성이 몇 이상이면 신호로 볼 것인가?

   ```python
   def classify_news_type(title):
       title_lower = title.lower()
       if any(word in title_lower for word in ['earnings', 'profit', 'revenue']):
           return 'earnings'
       elif any(word in title_lower for word in ['guidance', 'forecast', 'outlook']):
           return 'guidance'
       elif any(word in title_lower for word in ['lawsuit', 'sue', 'court']):
           return 'legal'
       elif any(word in title_lower for word in ['regulation', 'regulatory', 'sec', 'antitrust']):
           return 'regulatory'
       else:
           return 'other'
   ```

5. 부정성 점수 계산 함수 구현
   - 키워드 기반 방식 (버전 1):
   ```python
   def calculate_negativity_score(title):
       negative_keywords = ['miss', 'cut', 'warning', 'decline', 'loss', 'lawsuit', 'fine']
       positive_keywords = ['beat', 'raise', 'increase', 'growth', 'win']
       
       score = 0
       for keyword in negative_keywords:
           score += title.lower().count(keyword) * 0.2  # 부정 키워드당 +0.2
       for keyword in positive_keywords:
           score -= title.lower().count(keyword) * 0.2  # 긍정 키워드당 -0.2
       
       return max(-1.0, min(1.0, score))  # -1~1 범위로 정규화
   ```

6. 신호 발동 함수
   ```python
   def detect_news_signal(ticker, days=3, threshold=0.5):
       news_list = get_news(ticker, days=days)
       max_negativity = max([calculate_negativity_score(n['title']) for n in news_list], default=0)
       return max_negativity >= threshold
   ```

7. 종합 분석 함수
   ```python
   def analyze_news_sentiment(ticker, days=3):
       news_list = get_news(ticker, days=days)
       scores = [calculate_negativity_score(n['title']) for n in news_list]
       types = [classify_news_type(n['title']) for n in news_list]
       
       avg_score = sum(scores) / len(scores) if scores else 0
       has_signal = avg_score >= 0.5
       
       return {
           'negativity_score': avg_score,
           'news_types': list(set(types)),
           'signal': has_signal,
           'news_count': len(news_list)
       }
   ```
