## 작업 목적

요구사항 5.4-(1)에 명시된 **맥락 정보 제공**: "시장 전체 조정과 함께 하락한 경우도 알림 대상에서 제외하지 않되, 알림에 '시장 전체 조정인지 / 종목 고유 문제인지' 맥락 정보를 함께 제공"한다.

**계기 사례**: 코스트코, 펩시코는 종목 고유의 뚜렷한 뉴스나 이벤트 없이, 시장·섹터 전체 조정과 함께 서서히 하락했다. 이 경우 "시장이 함께 조정받고 있으니 단순히 지켜보되, 시장이 회복되면 함께 회복될 가능성도 있다"는 맥락이 중요하다.

이 정보는 P2.4(등급 판정)에서 "유지관찰 신호의 근거"로 사용되며, P3.1(알림 메시지)에 맥락으로 포함된다.

## 쉬운 설명

"어제 AAPL이 -3% 떨어졌는데, 동시에 S&P 500 전체가 -2.5% 떨어졌다면?"라고 물어보는 작업이다.

다시 말해:
1. 종목의 하락률: -3%
2. S&P 500 하락률: -2.5%
3. AAPL의 섹터(기술주) 하락률: -2.8%

→ "AAPL은 종목 고유의 문제가 아니라 시장 조정에 함께 휩쓸린 것일 수도 있다"

반대로:
1. 종목의 하락률: -5%
2. S&P 500 하락률: +0.5% (오름)
3. 섹터 하락률: +0.2% (오름)

→ "종목이 시장과 다르게 하락했다. 종목 고유의 문제가 있을 가능성이 높다"

5. 시장 조정 판단 함수 구현
   ```python
   def analyze_market_context(ticker, days=14):
       ticker_change = calculate_price_change_percentage(ticker, days)
       benchmark_change = calculate_price_change_percentage('^GSPC', days)
       sector_change = calculate_price_change_percentage(get_sector(ticker), days)
       
       # 판단: 종목과 벤치마크의 변화율 차이
       diff = ticker_change - benchmark_change
       
       # 예: 차이가 2% 이상이면 "종목 고유", 2% 미만이면 "시장 조정"
       is_market_adjustment = abs(diff) < 2.0
       
       return {
           'ticker_change': ticker_change,
           'benchmark_change': benchmark_change,
           'sector_change': sector_change,
           'is_market_adjustment': is_market_adjustment
       }
   ```

6. 맥락 메시지 생성 함수 추가

   def generate_market_context_message(ticker, days=14):
       context = analyze_market_context(ticker, days)
       if context['is_market_adjustment']:
           return f"시장 전체 {context['benchmark_change']:.1f}% 조정 중"
       else:
           return f"시장과 다르게 {context['ticker_change'] - context['benchmark_change']:.1f}% 더 하락"
