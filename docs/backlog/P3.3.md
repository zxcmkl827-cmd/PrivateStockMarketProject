## 작업 목적

**매일 정해진 시간에 자동으로** 다음 파이프라인 전체를 실행하는 스케줄러를 구현한다:

1. 데이터 수집 (가격, 뉴스, 벤치마크) — P1
2. 신호 계산 및 등급 판정 — P2
3. 알림 발송 — P3

요구사항 5.2절: "매일 자동 스캔, 이상 신호가 감지된 경우에만 알림 발송"

P0.1에서 결정된 기술 스택에 따라:
- 로컬 PC: Windows Task Scheduler 또는 cron
- 클라우드: Lambda, Cloud Functions, 또는 클라우드 native 스케줄러

## 쉬운 설명

"프로그램을 자동으로 매일 같은 시간에 실행하는 부분"이다. 사용자가 직접 클릭하지 않아도 시스템이 알아서:

1. 매일 오후 6시에 (또는 사용자가 지정한 시간에)
2. 모든 종목의 가격을 다운로드하고
3. 뉴스를 찾아보고
4. 신호를 계산하고
5. 필요하면 알림을 보낸다

그리고 다음 날도 같은 작업을 반복한다.

## 수행 순서

1. P1, P2, P3.2 완료 확인 (각 부분이 정상 작동하는가?)

2. 메인 파이프라인 함수 구현
   ```python
   # src/scheduler/pipeline.py
   from src.data_collection.prices import fetch_prices
   from src.data_collection.news import fetch_news
   from src.data_collection.benchmarks import fetch_benchmark_data
   from src.signal_analysis.rating_engine import judge_alert_rating
   from src.notification.message_generator import generate_alert_message
   from src.notification.sender import send_alert
   import logging
   
   logging.basicConfig(filename='data/scan.log', level=logging.INFO)
   
   def run_daily_scan():
       try:
           logging.info(f"[{datetime.now()}] 스캔 시작")
           
           # 1. 데이터 수집
           logging.info("데이터 수집 중...")
           my_stocks = ['AAPL', 'MSFT', 'COST', 'PEP']  # 사용자의 종목 리스트
           fetch_prices(my_stocks)
           fetch_news(my_stocks)
           fetch_benchmark_data(['^GSPC', 'XLK', 'XLF'])
           
           # 2. 신호 계산 및 판정
           logging.info("신호 계산 중...")
           alerts = []
           for ticker in my_stocks:
               rating = judge_alert_rating(ticker)
               if rating is not None:  # 신호 발동
                   alerts.append((ticker, rating))
           
           # 3. 알림 발송
           if alerts:
               logging.info(f"알림 발송: {len(alerts)}건")
               for ticker, rating in alerts:
                   message = generate_alert_message(ticker, rating)
                   send_alert(message)
           else:
               logging.info("알림 없음")
           
           logging.info(f"[{datetime.now()}] 스캔 완료")
       
       except Exception as e:
           logging.error(f"에러 발생: {e}")
           # 오류 알림 발송 (선택사항)
   
   if __name__ == "__main__":
       run_daily_scan()
   ```

## Done-when 확인 방법

백로그의 done_when: **"스케줄러가 최소 2일 연속 무개입으로 정상 실행됨을 확인하고, 그중 최소 1일은 어떤 종목도 등급 판정이 발생하지 않아 알림이 0건 발송되었음을 로그로 확인"**

확인 방법:

1. **파이프라인 함수 작동 확인**:
   ```bash
   python src/scheduler/pipeline.py
   ```
   - 에러 없이 실행되는가?
   - 로그에 "스캔 시작" ~ "스캔 완료" 메시지가 기록되는가?

2. **스케줄 설정 확인**:
   - **Windows**: Task Scheduler에 "Stock Alert Daily Scan" 작업이 생성되었는가?
   - **Linux**: `crontab -l`로 크론 작업이 등록되었는가?
   - **APScheduler**: 백그라운드 스케줄러가 실행 중인가?

3. **2일 연속 실행 로그 확인**:
   - `data/scan.log` 파일을 열어본다
   - 지난 2일의 실행 기록이 있는가?
   - 예:
     ```
     2026-09-14 18:00:01 [INFO] 스캔 시작
     2026-09-14 18:00:15 [INFO] 데이터 수집 중...
     2026-09-14 18:00:45 [INFO] 신호 계산 중...
     2026-09-14 18:01:00 [INFO] 알림 없음
     2026-09-14 18:01:01 [INFO] 스캔 완료
     
     2026-09-15 18:00:01 [INFO] 스캔 시작
     ... (동일한 패턴)
     2026-09-15 18:01:05 [INFO] 스캔 완료
     ```

4. **알림 발송 로그 확인** (신호 발동한 경우):
   - 신호가 감지되면 알림이 발송되었는가?
   - 발송 로그에 기록되었는가?

5. **오류 없음 확인**:
   - 로그 파일에 `[ERROR]`나 스택 트레이스가 없는가?
   - 있다면 무엇인가?

6. **신호 없는 날 확인** (done_when의 추가 조건):
   - 2일 중 최소 1일은 어떤 종목도 등급 판정이 발생하지 않았는가?
   - 그 날의 로그에 "알림 없음" 메시지가 기록되어 있는가?
   - 예:
     ```
     2026-09-14 18:00:01 [INFO] 스캔 시작
     2026-09-14 18:00:45 [INFO] 신호 계산 중...
     2026-09-14 18:01:00 [INFO] 알림 없음 ← 0건 발송 확인
     2026-09-14 18:01:01 [INFO] 스캔 완료
     ```

7. **최종 검증 표**:
   ```
   | 날짜 | 스케줄 실행 시간 | 데이터 수집 여부 | 신호 발동 여부 | 알림 발송 여부 | 성공 |
   |---|---|---|---|---|---|
   | 2026-09-14 | 18:00:01 | ✓ | 없음 | 없음(0건) | ✓ |

   ```
