## 작업 목적

**페이퍼 트레이딩 기간 동안 발생한 모든 알림과 실제 가격 추세를 기록**하여, P4.2에서 성공 기준을 판정할 수 있게 한다.

매일 P3.3 스케줄러가 자동으로 실행되면서:
1. 생성된 알림을 그냥 발송하는 것뿐 아니라 로그에도 저장
2. 각 알림에 대해 이후 며칠간의 실제 가격 변화를 추적
3. "이 알림 후 종목이 정말 떨어졌는가?"를 기록

그러면 나중에 "전체 알림 중 몇 개가 실제로 맞았는가?"를 계산할 수 있다.

## 쉬운 설명

"시스템이 낸 알림들을 모두 기록해서 나중에 검산할 수 있게 해두는 부분"이다.

예를 들어:
```
2026-09-20 18:00 AAPL [유지관찰] 가격 -4.8%, 뉴스 없음, 시장도 -3%
  → 추적 시작
  → 2026-09-21: AAPL 종가 $145 (-2.1%)
  → 2026-09-22: AAPL 종가 $143 (-4.1%)
  → 2026-09-23: AAPL 종가 $140 (-6.7%) ← 실제로 계속 떨어짐!
  → 평가: "성공" 또는 "부분 성공"

2026-09-25 18:00 MSFT [비중축소] 가격 -6%, 뉴스 있음
  → 추적 시작
  → 2026-09-26: MSFT 종가 $380 (+1.3%)
  → 2026-09-27: MSFT 종가 $385 (+2.8%)
  → 평가: "실패" (오히려 올랐음)
```

최종적으로 2개월 데이터를 보면: "전체 50개 알림 중 40개가 맞았다" = 80% 성공률

## 필요한 입력

- P3.3 스케줄러가 생성하는 **알림 메시지의 형식** (내용, 시간 등)
- **추적 기간**: 알림 후 몇 일까지 가격을 추적할 것인가?
  - 예: 알림 후 5일? 10일? 전체 관찰 기간?
  - 확인 질문: 추적 기간을 정해야 함

4. 로그 기록 함수 구현
   ```python
   import json
   from datetime import datetime
   
   def log_alert(ticker, rating, message, signals):
       with open('data/paper_trading_log.json', 'r') as f:
           log_data = json.load(f)
       
       alert_entry = {
           'alert_id': len(log_data['alerts']) + 1,
           'date': datetime.now().date().isoformat(),
           'time': datetime.now().time().isoformat(),
           'ticker': ticker,
           'rating': rating,
           'message': message,
           'signal_breakdown': signals
       }
       
       log_data['alerts'].append(alert_entry)
       
       with open('data/paper_trading_log.json', 'w') as f:
           json.dump(log_data, f, indent=2)
       
       return alert_entry['alert_id']
   ```
