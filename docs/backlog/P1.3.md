## 작업 목적

**벤치마크 지수(S&P 500)와 관련 섹터 지수 가격 데이터**를 매일 수집하여, P2.2(시장 전체 조정 여부 판단)에서 "개별 종목의 하락이 시장 전체 조정과 함께 발생했는가, 아니면 종목 고유의 문제인가"를 판단할 맥락 정보를 제공한다.

요구사항 문서의 계기 사례(코스트코, 펩시코)에서처럼 시장과 섹터 전체가 함께 하락한 경우, 이를 알림에 "시장 전체 조정"으로 표시할 수 있어야 한다.

## 쉬운 설명

"전체 시장(S&P 500)과 특정 산업(예: 기술주, 금융주)의 지수도 매일 함께 수집하는 작업"이다.

예를 들어:
- AAPL이 어제 -3% 떨어졌다고 하자
- 그런데 같은 날 S&P 500도 -2% 떨어졌고, 기술주 지수(XLK)도 -2.5% 떨어졌다면?
- "AAPL이 떨어진 것은 전체 시장 조정의 일부일 수도 있다"는 맥락을 제공할 수 있다
- 알림: "AAPL 유지관찰 (시장 전체 -2% 조정 중)"

반대로:
- COST가 -3% 떨어졌는데
- S&P 500은 +0.5% 올랐고, 소비재 지수(XLP)는 +0.2% 올랐다면?
- "COST의 하락은 시장 조정이 아니라 종목 고유의 문제"라고 판단할 수 있다
- 알림: "COST 유지관찰 (시장과 다르게 하락)"

## 필요한 입력

- P0.3에서 확정된 **가격 데이터 소스** (벤치마크 데이터도 같은 소스에서 가져올 수 있어야 함)
- **벤치마크 지수 목록**:
  - S&P 500 (기호: ^GSPC 또는 ^SPX)
  - 섹터 지수 최소 1개 (예: XLK 기술주, XLF 금융주, XLV 헬스케어주 등)
- **사용자의 포트폴리오 섹터 정보** (어떤 섹터에 집중되어 있는가?)

## 결과물

1. **벤치마크 수집 함수**
   ```
   def fetch_benchmark_data(indices, start_date, end_date):
       # indices: ['^GSPC', 'XLK', 'XLV', ...]
       # 반환: 각 지수의 일일 가격 데이터
   ```

2. **저장된 벤치마크 데이터** (테스트 증거)
   - S&P 500, 최소 1개 섹터 지수의 최근 데이터가 저장된 상태
   - 예:

3. **섹터 매핑 정보** (선택사항이지만 권장)

   - 이를 통해 P2.2에서 "AAPL이 속한 섹터 지수와 비교"할 수 있음

## 수행 순서

1. P0.3 결과 확인 (가격 소스가 벤치마크 데이터도 제공하는가?)

2. 벤치마크 지수 기호 확정
   - S&P 500: ^GSPC, ^SPX, 또는 기타 소스 기호
   - 섹터 지수: XLK(기술), XLF(금융), XLV(헬스케어), XLE(에너지), XLY(소비재), XLP(필수소비재) 등 중 선택
   - 사용자 포트폴리오의 섹터별 비중을 고려해서 선택

3. 프로젝트 스캐폴드에 `src/data_collection/benchmarks.py` 생성

4. 벤치마크 수집 함수 구현
   ```python
   import yfinance as yf
   
   def fetch_benchmark_data(indices):
       data = {}
       for index in indices:  # ['^GSPC', 'XLK', ...]
           data[index] = yf.download(index, period='1y')
       return data
   ```

5. 데이터 저장 로직 구현

6. 테스트 실행
   - S&P 500 데이터 수집 및 저장
   - 섹터 지수 데이터 수집 및 저장
   - 데이터 정확성 검증

## Done-when 확인 방법

3. **데이터 정확성 확인**:

