## 작업 목적

프로젝트 전체의 개발 방향을 결정하는 스파이크 작업이다. 무료 데이터 소스에 접근 가능하면서도, 매일 1회 자동 실행과 카카오톡/이메일 알림 발송이 모두 가능한 기술 조합을 사용자와 함께 검토하여 확정한다. 이 결정이 나오면 P0.2(스캐폴드)와 P0.3(데이터 소스 조사)의 방향이 정해진다.

## 쉬운 설명

"이 프로젝트를 만들기 위해 어떤 도구와 서비스를 써야 하는가"를 결정하는 단계다.

예를 들어:
- **언어**: Python으로 할 것인가, Node.js로 할 것인가, 아니면 다른 언어인가?
- **실행 환경**: 개인 컴퓨터에서 항상 켜서 실행할 것인가, 클라우드(AWS, Azure 등)를 쓸 것인가, 아니면 무료 호스팅(Heroku 등)을 쓸 것인가?
- **자동화**: 매일 같은 시간에 자동으로 실행하려면 어떤 도구를 써야 하나?
- **알림**: 카카오톡이나 이메일로 알림을 보내는 것이 기술적으로 가능한가? 그리고 그 비용은 무료인가?

이런 것들을 체크리스트로 확인하면서 사용자와 함께 최종 선택을 한다.

## 필요한 입력

- 사용자의 기술 선호도 (어떤 언어를 편하게 생각하는가)
- 실행 환경 제약 (집 컴퓨터만 사용 가능한가, 클라우드 비용을 쓸 수 있는가)
- 알림 채널 선호도 (카카오톡, 이메일, Slack 등)
- 무료 서비스 제약사항 (사용할 수 없는 서비스나 플랫폼이 있는가)

## 결과물

최소한 다음 정보가 정확하고 구체적으로 문서화됨:
1. **프로그래밍 언어** (예: Python 3.10+)
2. **실행 환경/배포 방식** (예: 로컬 Windows PC + Python 스크립트, 또는 AWS Lambda, 또는 Heroku 등)
3. **자동 스케줄링 방식** (예: Windows Task Scheduler, Linux cron, APScheduler, 또는 클라우드 기본 제공 스케줄러)
4. **알림 발송 채널**
   - 카카오톡: 사용할 API 또는 서비스 (예: 카카오 메시지 API)
   - 이메일: 발송 서비스 (예: Gmail SMTP, SendGrid 무료 계정)
5. **선택 이유** (왜 이 조합을 선택했는가 — 비용, 난이도, 기술 가용성 등)

## 수행 순서

1. 사용자와 대면 또는 서면으로 요구사항 재확인
   - 어느 환경에서 실행할 것인가? (로컬 PC vs 클라우드)
   - 알림 채널은? (카카오톡 우선인가, 이메일도 함께인가?)
   - 기술 선호도가 있는가? (특정 언어나 프레임워크)

2. 각 기술 영역별로 후보 3~4개씩 조사
   - 언어: Python, JavaScript, Java 등 중 선택 (확인 질문: 프로젝트가 특정 언어로 제한되는가?)
   - 스케줄링: cron, APScheduler, Celery, 클라우드 서비스 등
   - 알림: 각 채널별로 무료 API 가용성 확인

3. 각 조합을 비용, 복잡도, 유지보수성 관점에서 비교 평가

4. 최종 1개 조합을 선택하고 사용자 승인 받음

5. CLAUDE.md의 "기술 스택" 섹션(아직 미정의 상태)에 최종 결정사항 기록
