## 작업 목적

P3.1에서 작성된 **알림 메시지를 실제로 사용자에게 발송**한다. 요구사항 5.7절에 명시된 대로 **카카오톡, 이메일 등 간단한 알림 수단**을 사용한다.

P0.1에서 결정된 기술 스택에 따라:
- 카카오톡: 카카오톡 메시지 API 또는 봇
- 이메일: Gmail, SendGrid, 또는 기업 SMTP 서버

중 하나 또는 둘 다를 선택해 연동한다.

## 쉬운 설명

"프로그램이 생성한 메시지를 실제로 사용자의 카카오톡이나 이메일로 보내는 부분"이다.

예를 들어:
1. P3.1에서 "AAPL - 유지관찰 / -4.8% 하락" 메시지를 생성했다
2. 이제 이 메시지를 사용자의 카카오톡에 전송한다
3. 또는 사용자의 이메일로 전송한다

## 필요한 입력

- P0.1에서 결정된 **알림 채널** (카카오톡, 이메일, 둘 다)
- **인증 정보**:
  - 카카오톡: 카카오톡 API 키, 또는 봇 토큰
  - 이메일: SMTP 서버 정보, 계정, 비밀번호
- **수신자 정보**:
  - 카카오톡: 사용자의 카카오톡 ID 또는 휴대폰 번호
  - 이메일: 사용자의 이메일 주소
- **발송 설정** (사용자 선호도):
  - 채널별 발송 여부
  - 메시지 형식 (텍스트 vs HTML)

4. 카카오톡 발송 구현 (선택됨)
   ```python
   import requests
   
   def send_kakao_message(message):
       # 카카오톡 메시지 API 호출
       url = 'https://kapi.kakao.com/v2/api/talk/memo/default/send'
       headers = {
           'Authorization': f'Bearer {KAKAO_ACCESS_TOKEN}',
           'Content-Type': 'application/x-www-form-urlencoded'
       }
       params = {
           'template_object': json.dumps({
               'object_type': 'text',
               'text': message
           })
       }
       response = requests.post(url, headers=headers, params=params)
       return response.status_code == 200
   ```

5. 이메일 발송 구현 (선택됨)
   ```python
   import smtplib
   
   def send_email_message(message):
       # Gmail SMTP 사용
       sender = 'your_email@gmail.com'
       password = 'your_app_password'  # 2FA 설정 후 앱 비밀번호
       recipient = 'user_email@example.com'
       
       with smtplib.SMTP_SSL('smtp.gmail.com', 465) as server:
           server.login(sender, password)
           email_body = f"""
           Subject: Stock Alert
           
           {message}
           """
           server.sendmail(sender, recipient, email_body)
       
       return True
   ```

6. 통합 발송 함수 구현

   ```python
   def send_alert(message, channels=['kakao', 'email']):
       results = {}
       if 'kakao' in channels:
           results['kakao'] = send_kakao_message(message)
       if 'email' in channels:
           results['email'] = send_email_message(message)
       return results
   ```

확인 방법:

1. **함수 작동 확인**:
   ```python
   from src.notification.sender import send_alert
   
   test_message = "[테스트] Apple - 유지관찰 / -4.8% 하락"
   results = send_alert(test_message, channels=['kakao', 'email'])
   print(results)
   # 예상: {'kakao': True, 'email': True}
   ```

2. **실제 발송 확인**:
   - **카카오톡**: 사용자의 카카오톡 앱에서 테스트 메시지가 수신되었는가?
   - **이메일**: 사용자의 이메일 받은편지함에서 테스트 메시지가 수신되었는가?
   - 스크린샷 또는 캡처로 증거 기록

3. **채널별 발송 테스트**:
   - 카카오톡만 발송: 카카오톡만 수신, 이메일은 안 옴
   - 이메일만 발송: 이메일만 수신, 카카오톡은 안 옴
   - 둘 다 발송: 둘 다 수신

4. **실패 케이스 테스트**:
   - API 키가 잘못된 경우: 에러 처리 정상 여부
   - 이메일 주소가 잘못된 경우: 에러 처리 정상 여부
   - 네트워크 오류 시뮬레이션: 재시도 또는 경고 정상 여부

5. **발송 로그 확인**:
   - `data/send_history.json` 또는 `data/send_history.db`에 기록이 저장되었는가?
   - 기록에 날짜, 채널, 성공 여부가 모두 포함되었는가?
