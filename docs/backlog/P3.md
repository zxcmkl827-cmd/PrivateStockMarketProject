## 작업 목적

프로젝트의 세 번째 단계로, P2에서 계산한 등급 판정 결과를 기반으로 **실제 알림을 사용자에게 발송**한다. 요구사항 5.6~5.7절에 명시된 대로:

1. **알림 메시지 설계** (종목명 + 등급 + 판단 근거 + 행동 제안)
2. **카카오톡/이메일 채널 연동** (실제 발송)
3. **매일 자동 스캔 스케줄러** (P0에서 결정된 스케줄링 방식으로)

이 단계를 완료하면, 매일 정해진 시간에 자동으로 모든 종목을 스캔하고, 이상이 감지되면 사용자에게 알림이 오는 기본 시스템이 완성된다.

## 쉬운 설명

"시스템이 계산한 '이 종목이 주의 필요'라는 판단을 사용자에게 전달하는 방법"이다.

예를 들어:
1. **알림 작성**: "COST - 유지관찰 / 최근 2주 -5.2% 하락 중"이라는 메시지를 만든다
2. **발송**: 매일 오후 6시에 자동으로 카카오톡이나 이메일로 이 메시지를 보낸다
3. **반복**: 내일, 모레, ... 계속 반복한다

## 필요한 입력

- P2.4 완료 (등급 판정 엔진)
- P0에서 결정된 **알림 채널** (카카오톡, 이메일, 둘 다)
- **알림 메시지 포맷** 결정 (P3.1에서)

## 결과물

세 개의 모듈로 이루어진 알림 시스템:

1. **알림 메시지 포맷 정의** (P3.1에서 구현)
   - 샘플 메시지 템플릿
   - 사용자 승인

2. **채널별 발송 연동** (P3.2에서 구현)
   - 카카오톡 API / 이메일 SMTP 구현
   - 실제 테스트 메시지 발송 확인

3. **매일 자동 스케줄러** (P3.3에서 구현)
   - 정해진 시간에 전체 파이프라인 자동 실행
   - 최소 2일 연속 무개입 실행 확인
