이는 요구사항 5.8절(사후 검증 및 가중치 자동 조정)에 기술된 기본 정책을 보완한 것이다:

**배경**:
- 사용자 초기 요청(2026-09-16): 가격 신호는 1거래일 후 종가로 빨리 판정 가능하므로 매일 피드백받고 싶음 (뉴스는 1주/2주 유지)
- Critical-reviewer 검토 결과: 가격 근거에만 1일 판정을 적용하면 두 가지 문제 발생

  2. 1일 임계값 -2%는 원래 "10거래일 누적 하락"을 판정하는 지표인데 "바로 다음 거래일 추가 -2%"로만 채점하면 구조적으로 적중률 저하 → 복리 문제와 겹쳐 가격 근거 가중치가 하한으로 수렴, 핵심 기능(가격 기반 비중축소)이 무력화될 위험
- **최종 설계** (2026-09-16 사용자 확정):
  1. 1거래일/1주/2주 판정을 모든 근거에서 모두 계산 (공통 로직)
  2. 리포트·알림 이력에는 세 판정 모두 표시 (1일은 별도 라벨로)
  3. 가중치 자동조정에는 1주/2주 판정만 집계, 1일 판정은 절대 미사용
  4. 재조정 쿨다운 추가: 직전 조정 이후 동일 근거 유형에서 최소표본만큼 새 표본이 쌓여야 재조정 가능
  5. "매도" 등급의 가격+강한뉴스 동시확인 구조 규칙은 가중치로 무력화되지 않는 고정 안전장치로 유지

## 쉬운 설명

"알림이 생길 때마다 1거래일 후, 1주 후, 2주 후의 종가를 모두 기록하고, 사후에 적중/과잉감지를 판정한다. 리포트에는 세 판정 모두 표시해서 사용자가 볼 수 있게 하지만, 자동으로 가중치를 조정할 때는 1주/2주 판정만 쓰고 1거래일 판정은 사용하지 않는다. 그리고 같은 근거 유형을 매일 재조정하는 대신, 직전 조정 이후 최소 10개의 새로운 판정 기록이 쌓여야만 다시 조정한다"는 개념이다.

예를 들어:
```
알림 기록 및 사후검증:
┌─────────────────────────────────────────────────────────┐
│ AAPL, 2026-09-15 [유지관찰]                              │
│ 근거: price_decline (가격 하락)                          │
│ → 2026-09-16(다음거래일): -1.5% → 1일 판정: 적중         │
│ → 2026-09-22(1주): +0.5% → 1주 판정: 과잉감지            │
│ → 2026-09-29(2주): +2.0% → 2주 판정: 과잉감지            │
│   → 리포트에는 세 판정 모두 기록                         │
│   → 가중치 조정: 1주/2주 판정(둘 다 과잉감지)만 고려     │
│                                                        │
│ MSFT, 2026-09-15 [비중축소]                              │
│ 근거: news_regulatory_legal_political (규제 뉴스)        │
│ → 2026-09-16(다음거래일): -0.8% → 1일 판정: 미판정       │
│ → 2026-09-22(1주): -2.1% → 1주 판정: 적중                │
│ → 2026-09-29(2주): -4.5% → 2주 판정: 적중                │
│   → 리포트에는 세 판정 모두 기록                         │
│   → 가중치 조정: 1주/2주 판정(둘 다 적중)만 고려,        │
│      직전 조정 이후 news_regulatory_legal_political이    │
│      새로 10건 축적되어야 다시 조정                     │
└─────────────────────────────────────────────────────────┘
```
