## 작업 목적

요구사항 5.4-(1)에 명시된 **절대 하락률 신호**를 계산한다. 이것은:

- **기준**: 벤치마크 대비 상대 성과가 아닌 **절대 하락률**
- **민감도**: 1~2주 내 **-5% 내외의 하락**을 감지
- **계기 사례**: 코스트코, 펩시코가 -10%~-20% 손실 상태에 빠지기 전에 조기에 이 신호를 포착해야 했음

이 신호는 P2.4(등급 판정)의 입력이 되며, P2.2(시장 조정 판단)의 기초도 제공한다.

## 쉬운 설명

"종목의 가격이 '요즘 들어' 얼마나 떨어졌는가"를 자동으로 계산하는 부분이다.

예를 들어:
- 2주 전에 AAPL이 $150였다
- 오늘 AAPL이 $142다
- 하락률 = (142 - 150) / 150 = -5.3%
- "신호 발동! AAPL이 최근 2주에 -5% 이상 떨어졌다"

**중요한 포인트**: 벤치마크(시장 전체)와 비교하는 것이 아니라, **절대적으로 떨어진 정도를 본다**. 왜냐하면:
- 코스트코가 -3% 떨어졌는데 시장 전체가 -2% 떨어졌다면?
- 상대적으로는 "시장보다 0.5% 더 떨어짐"이지만
- 절대적으로는 "투자자가 여전히 3% 손실"이므로 주의가 필요하다

## 필요한 입력

- P1.1에서 수집된 **종목 가격 데이터** (최근 30~60일)
- **하락률 임계값**: 얼마나 떨어지면 "신호"로 볼 것인가?
  - 요구사항에서: "1~2주 내 -5% 내외" → 임계값을 -5%로 설정할 수 있음
  - 확인 질문: 정확한 임계값은 무엇인가?
- **계산 기간**: 며칠을 "최근"으로 볼 것인가?
  - 요구사항에서: "1~2주" → 7~14일
  - 확인 질문: 정확히 며칠로 설정할 것인가?

3. 하락률 계산 함수 구현
   ```python
   def calculate_price_change_percentage(ticker, days=14):
       # DB에서 최근 N일의 가격 데이터 조회
       prices = get_prices(ticker, days=days)
       if len(prices) < 2:
           return None
       
       # 시작가, 현재가 비교
       start_price = prices[0]['close']
       current_price = prices[-1]['close']
       
       change_pct = ((current_price - start_price) / start_price) * 100
       return change_pct
   ```

4. 신호 발동 함수 구현
   ```python
   def detect_price_signal(ticker, threshold=-5, days=14):
       change_pct = calculate_price_change_percentage(ticker, days)
       if change_pct is None:
           return False
       return change_pct <= threshold  # 하락률이 임계값 이하면 True
   ```

5. 테스트 케이스 작성
   - 하락률이 -6%인 경우: 신호 발동 (True)
   - 하락률이 -3%인 경우: 신호 미발동 (False)
   - 가격 데이터가 불완전한 경우: 에러 처리

## Done-when 확인 방법

백로그의 done_when: **"임계값(관측창 거래일 수, 하락률)이 설정값으로 외부화되어 있고, 요구사항 5.4-(1)의 기본값(관측창 1~2주≈10거래일, 하락률 -5% 내외)에서 지정 구간의 하락일에는 신호가 발생하고 직전 횡보 구간에는 발생하지 않음을 확인"**

확인 방법:

1. **함수 작동 확인**:
   - 프로젝트에서 함수를 실행
   ```python
   from src.signal_analysis.price_signals import calculate_price_change_percentage, detect_price_signal
   
   change = calculate_price_change_percentage('AAPL', days=14)
   signal = detect_price_signal('AAPL')
   print(f"AAPL 14일 변화율: {change}%")
   print(f"신호 발동: {signal}")
   ```

2. **과거 회귀 테스트**:
   - 코스트코(COST)의 2~3년 전 데이터에서 실제 큰 하락이 있었던 기간을 찾는다
   - 그 기간의 14일 하락률을 계산해서 신호가 올바르게 발동하는가 확인
   - 예: 2024년 Q2-Q3에 COST가 -10% 이상 떨어졌다면, 그 기간 중 어느 14일 구간에서 -5% 이상 하락이 포착되는가?

확인 질문:
