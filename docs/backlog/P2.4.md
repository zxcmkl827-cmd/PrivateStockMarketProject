## 작업 목적

이 프로젝트의 **핵심 판단 엔진**이다. P2.1, P2.2, P2.3에서 계산한 세 가지 신호를 결합하여, 최종적으로 **유지관찰 / 비중축소 / 매도** 중 하나의 등급을 판정한다.

요구사항 5.5절의 핵심 설계 원칙 (CLAUDE.md 참고):
- **유지관찰**: 신호 1개만 있어도 발동 (recall 우선, 민감하게)
- **비중축소**: 유지관찰보다 강하거나 복수 신호의 부분적 결합
- **매도**: 복수 신호가 동시에 확인될 때만 발동 (precision 우선, 신중하게)

이유: 사용자가 "매도" 등급을 받으면 근거를 보고 거의 그대로 실제 매도를 실행한다. 오탐은 금전적 손실로 이어지므로 신중해야 하며, 반대로 "유지관찰"은 단순 지켜보기이므로 민감하게 자주 떠도 괜찮다.

## 쉬운 설명

"가격 신호, 뉴스 신호, 시장 맥락을 종합해서 '이 종목은 지금 주의해야 하나?'라고 최종 판단하는 부분"이다.

예를 들어:

| 상황 | 가격 신호 | 뉴스 신호 | 판정 | 이유 |
|---|---|---|---|---|
| A | 하락 -6% | 부정 있음 | **매도** | 복수 신호 동시 |
| B | 하락 -5% | 부정 없음 | 유지관찰 | 신호 1개 (가격) |
| C | 하락 없음 | 부정 있음 | 유지관찰 | 신호 1개 (뉴스) |
| D | 하락 없음 | 부정 없음 | - | 신호 없음 (알림 안 함) |
| E | 하락 -7% | 약간 부정 | **비중축소** | 복수 신호의 부분적 결합 |

## 필요한 입력

- P2.1에서 계산된 **절대 하락률 신호** (bool)
- P2.2에서 계산된 **시장 조정 여부** (bool) + 맥락
- P2.3에서 계산된 **뉴스 부정성** (0~1 점수) + 뉴스 유형

4. 등급 판정 함수 구현
   ```python
   def judge_alert_rating(ticker, days=14):
       # 신호 계산
       price_signal = detect_price_signal(ticker, days=days)
       price_change = calculate_price_change_percentage(ticker, days=days)
       market_context = analyze_market_context(ticker, days=days)
       news_sentiment = analyze_news_sentiment(ticker, days=days)
       
       # 신호 강도 평가
       price_strength = abs(price_change) / 10  # -10%이면 강도 1.0
       news_strength = news_sentiment['negativity_score']
       
       # 판정 로직
       signal_count = sum([price_signal, news_sentiment['signal']])
       
       if signal_count == 0:
           return None  # 신호 없음
       elif signal_count == 1:
           return 'watch'  # 유지관찰
       elif signal_count == 2:
           # 복수 신호 → 강도에 따라 비중축소 또는 매도
           if price_strength >= 0.8 or news_strength >= 0.8:
               return 'sell'  # 매도
           else:
               return 'reduce'  # 비중축소
       else:
           return None  # 예상치 못한 경우
   ```
